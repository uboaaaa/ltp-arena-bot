# LTP Hackathon Trading Bot

An automated trading agent for the Liquidity Arena AI quant hackathon (Binance perp futures and simulated funds)

## Setup
1. Copy `env.example` to `.env` and fill in the corresponding credentials
2. `python -m venv .venv` and activate it
3. `pip install -r requirements.txt`
